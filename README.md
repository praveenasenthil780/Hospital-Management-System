# Hospital Management System

A simple Hospital Management System developed using Python, Tkinter, and SQLite.

## Features

- Patient Management
- Doctor Management
- Appointment Management
- Prescription Management
- Billing Management
- Room Management
- Discharge Management
- User Registration
- Login System
- Change Password
- Reports
- PDF Report Generation
- Search Records

## Technologies Used

- Python
- Tkinter
- SQLite
- ReportLab

## Database

The project uses SQLite database.

Database file:

hospital.db

## Installation

Install ReportLab:

```bash
pip install reportlab
Run the Project

Run the main file:

python main.py
